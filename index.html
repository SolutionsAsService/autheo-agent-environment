PQC migration phases

  1. P0 · agilitySuite registry, ML-DSA did:key, hybrid proof sets, key binding, verifier policy, Python == Node vectors. Done in 0.4 (experimental).
  2. P1 · hybrid chainsDelegations, invocations, revocations and receipts carry hybrid proofs; per-environment policy; did bind CLI/API; downgrade tests.
  3. P2 · PQ KEMHybrid X25519 + ML-KEM envelopes done in 0.5; next: hybrid TLS (X25519MLKEM768), pure MLKEM1024 under max, zkTLS attestations.
  4. P3 · PQ defaultHybrid required for new evidence; SLH-DSA for long-lived roots and ledger anchors.
  5. P4 · PQ-onlyPolicy pq for regulated tenants; external audit; CNSA 2.0 alignment.
